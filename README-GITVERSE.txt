КАК ОПУБЛИКОВАТЬ ЭТОТ САЙТ НА GITVERSE PAGES
=============================================
Сборка от 07.10 · раунд 27 · пути относительные — работает в ЛЮБОЙ подпапке.

В архиве — ГОТОВАЯ статическая сборка сайта (index.html + ассеты + шрифты).
Ничего устанавливать и собирать не нужно: git, распаковка, push.

ШАГИ
----
1. Распакуйте архив в отдельную папку. Внутри должен лежать index.html
   (рядом папки _next, fonts, favicon.svg, icon-*.png, og-image.png,
   файлы 404.html и .nojekyll).

2. Создайте репозиторий на gitverse.ru (без README и .gitignore).

3. В папке с распакованным сайтом:

   git init
   git add .
   git commit -m "Курс: статическая сборка"
   git remote add origin https://gitverse.ru/ВАШ_ЛОГИН/ИМЯ-РЕПО.git
   git push -u origin master
   # если просит логин-пароль — используйте логин и ТОКЕН из настроек
   # GitVerse (Профиль → Настройки → Токены), не пароль от аккаунта

4. В репозитории на gitverse.ru откройте Настройки → Pages
   и включите публикацию: ветка master (или main), папка — корень «/».
   (если GitVerse предлагает выбор только папки /docs — просто
   переложите все файлы из корня в папку docs/ и закоммитьте)

5. Через минуту сайт будет доступен по адресу вида:
   https://ВАШ_ЛОГИН.gitverse.ru/ИМЯ-РЕПО/

ВАЖНО ПРО ПУТИ (что было исправлено в этой сборке)
--------------------------------------------------
Раньше файлы стилей и скриптов подключались от корня домена (/_next/…)
и на GitVerse Pages, где сайт живёт в подпапке /ИМЯ-РЕПО/, не загружались —
страница открывалась «голым» нестилизованным текстом. Теперь ВСЕ пути
относительные: сборка работает в корне домена, в подпапке репозитория
и в папке /docs. Ссылку на сайт можно открывать и без завершающего
слэша — встроенный скрипт сам дополняет адрес до /ИМЯ-РЕПО/ до того,
как браузер начнёт запрашивать файлы.

ОТЛИЧИЕ СТАТИЧЕСКОЙ ВЕРСИИ
--------------------------
GitVerse Pages хостит только статику, поэтому облачная синхронизация
(6-символьные коды) здесь отключена и заменена карточкой-пояснением:
прогресс тетради хранится в localStorage браузера (переживает
перезагрузку), а перенос между устройствами — через «Экспорт JSON» /
«Импорт JSON» внизу тетради или печать в PDF.

Полная версия с облаком: см. архив course-digital-communication.zip
и README.md в нём (деплой на VPS / Docker / Vercel+Postgres).
